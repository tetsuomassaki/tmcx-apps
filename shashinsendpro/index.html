ShashinSendPro

内蔵カメラ・外部カメラ（HDMIキャプチャボード）で撮影し、LAN上の WebDAV サーバーへ転送するタブレット専用の業務用カメラアプリ

App Store

機能

  • 内蔵カメラ／外部カメラ（HDMIキャプチャボード）に対応
  • 撮影と転送を分離した高速シャッター。連写してもテンポが落ちません
  • 撮影 ID 単位でのグループ管理。ミリ秒精度のファイル名で連写の衝突を防止
  • ネットワーク復帰時に未送信を自動再送。未送信件数はバッジで表示
  • HEIC → JPEG 自動変換（カメラ切替で推奨設定を自動。手動上書きも可）
  • 送信履歴の保持期間管理。成功記録は期間経過で自動整理
  • デモモード：WebDAV サーバーが無くても撮影〜履歴の動作を確認可能
  • パスワードは iOS Keychain に保存。画像はユーザー指定の WebDAV サーバーにのみ送信し、開発元サーバーには送りません

こんな現場で

  • 院内・施設内 LAN への写真取り込み
  • 検査・処置の記録撮影、経過観察
  • 外部カメラ（キャプチャボード）を使った撮影運用

動作要件

  • タブレット専用（対応OS 17.0 以上）
  • 写真の転送先となる WebDAV サーバー（ユーザー側でご用意ください）
  • 外部カメラ利用時：USB-C 接続の HDMI キャプチャボード（任意）

免責事項

Features

  • Capture from the built-in camera or an external camera (HDMI capture board)
  • Capture decoupled from transfer for a responsive shutter — burst capture stays fast
  • Capture-ID grouping with millisecond-precise file names to avoid collisions
  • Auto-resend of unsent items on reconnect; an unsent-count badge keeps you informed
  • Automatic HEIC → JPEG conversion (recommended default set per camera; overridable)
  • Transfer history with retention management; successful records are cleaned up automatically
  • Demo Mode lets you exercise the capture-to-history flow without a WebDAV server
  • Passwords stored in iOS Keychain; images are sent only to your WebDAV server, never to the developer

Requirements

  • A tablet running OS 17.0 or later
  • A WebDAV server (provided by the user) as the transfer destination
  • For the external camera: a USB-C HDMI capture board (optional)
